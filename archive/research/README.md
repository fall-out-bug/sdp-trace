# Research And Historical Artifacts

This directory is an archive of research notes, reviewer outputs, pilot reports,
block ledgers, and implementation evidence.

It is not the onboarding path for `sdp-trace`. Start with
[the documentation map](../README.md) instead.

## Authority Boundary

Files in this directory may be useful evidence of past reasoning or past runs,
but they are not current product proof by themselves.

Use them only with their stated scope:

- reviewer-role files are review artifacts, not product documentation;
- implementation plans and ledgers are development records, not user
  onboarding;
- checked-in reports describe the run they name, not broad harness or model
  compatibility;
- stale CI, run, or proof claims must be replayed with current commands before
  being treated as authority.

For current command behavior, use `go run ./cmd/sdp-trace --help` and
`docs/agent-entrypoint.md`.
