Status: example-only, not product proof
Contract: Product Contract v0

This example shows the intended buyer artifact shape. It is not generated by
current product code and must not be used as evidence that packet generation is
implemented.

## Executive Summary

Change `PAY-1842` modified payment retry logic. The repository mutation is
observable from Git refs. The agent route is partially observed from an
OpenCode/GSD session run. Test verification is agent-claimed and
harness-observed, but no independent retained CI or customer witness artifact is
available. Review ownership is not assessed. The next merge decision owner is
asserted but not bound to policy or change-host metadata.

This packet does not approve merge, release, compliance, production trust, or
employee action. It records evidence, gaps, and decision ownership.
