### P1 — Claim tag evidence references violate grammar

**3. docs/roadmap.md (last line), `final-evidence-map.md` (last line), `tasks.md` (last line)**

All three claim tags use evidence references that don't conform to the grammar in `docs/claim-authoring.md`:

```
Actual:   evidence=command_set:015-roadmap-verification
           evidence=command_set:015-local-verification
Allowed:  evidence=command_set:block04-t070  (example from grammar)
```

The grammar requires `command_set:<block>-<task>` format referencing a specific task. `015-roadmap-verification` and `015-local-verification` are not valid block-task references. They should be something like `command_set:block015-t030` (referencing T030, the verification task).

**Fix**: Replace with actual task references:
- `docs/roadmap.md` → `command_set:block015-t030` (or whichever task owns roadmap verification)
- `final-evidence-map.md` → `command_set:block015-t030`
- `tasks.md` → `command_set:block015-t030` (same verification gate task)
